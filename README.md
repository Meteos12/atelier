# リディー＆スールのアトリエ 特性引き継ぎルート

カテゴリ間で特性を運ぶための中継調合品を検索する、GitHub Pages向けの小型攻略ツールです。

## 使い方

1. FROMに特性を持っている素材のカテゴリを選択
2. TOに特性を持っていきたいカテゴリを選択
3. 最短の引き継ぎルートを確認
4. 「カテゴリ一覧」ではカテゴリ変換マトリクスから直接ルートを選択

例：魚介類 → 宝石

魚介類 → おいしそうな練り餌 → 粘土 → 中和剤・黄 → 中和剤 → 錬金粘土 → ジェット原石 → 宝石

## データについて

レシピ・カテゴリの整理にはリディー＆スールのアトリエ Wiki* の「調合」「調合逆引き」等を参照しています。

https://wikiwiki.jp/lydie/調合/調合
https://wikiwiki.jp/lydie/調合逆引き

ゲーム内のカテゴリ付与効果（例：中和剤・赤の「火薬付与」）は、通常の「調合品そのものが持つカテゴリ」と別ルールです。今後、必要なら「カテゴリ付与効果」も検索対象に追加できます。

## GitHub Pages

リポジトリの Settings → Pages で main / root を公開すると利用できます。
