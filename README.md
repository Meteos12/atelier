# リディー＆スールのアトリエ 特性引き継ぎルート

カテゴリ間で特性を運ぶための中継調合品を検索する、GitHub Pages向けの小型攻略ツールです。

## 使い方

1. FROMに特性を持っている素材のカテゴリを選択
2. TOに特性を持っていきたいカテゴリを選択
3. 最短の引き継ぎルートを確認
4. 「カテゴリ一覧」ではカテゴリ変換マトリクスから直接ルートを選択

例：魚介類 → 宝石

魚介類 → おいしそうな練り餌 → 粘土 → ポリッシュ → ジェット原石など、実際の調合品を何段階も中継するルートを探索できます。

## データについて

41カテゴリを対象に、通常調合だけでなく「攻撃」「回復」「補助」「探索」「装飾品」まで含めた175件のレシピを登録しています。DLCレシピは画面上でON/OFFでき、さらに中和剤・赤/青/黄/緑/紫のカテゴリ付与効果も別ルールとしてON/OFFできます。

レシピ・カテゴリの整理にはリディー＆スールのアトリエ Wiki* を参照しています。

### ルートの考え方

カテゴリ → 調合品 → カテゴリだけでなく、調合したアイテムそのものを次のレシピへ渡す「完成品連鎖」もグラフとして扱っています。これにより、例えば「魚介類 → おいしそうな練り餌 → 粘土 → 錬金粘土 → ジェット原石 → 宝石」のようなルートを検索できます。

## GitHub Pages

リポジトリの Settings → Pages で main / root を公開すると利用できます。
